# CampusNav App Access

The mobile app starts on a welcome screen. Tapping **Get Started** opens the map; users do not need to sign in or create an account to browse campus locations and search. Use the back arrow beside the map logo to return to the welcome screen.

Set `EXPO_PUBLIC_API_URL` to the API server URL if the app needs API-backed campus content. For VS Code Dev Tunnels, forward port `8080` and use its HTTPS URL.
